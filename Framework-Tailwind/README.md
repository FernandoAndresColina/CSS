### Clase del framework tailwind

1. Intalamos la extension Tailwind CSS IntelliSense.
2. npm install -D tailwindcss postcss autoprefixer, para instalarlo como dependencia de desarrollo al instalar estos 3 segun la documentacion de tailwind son los paquetes recomendados.
3. npx tailwindcss init -p, para inicializar una confirguracion de tailwing.
